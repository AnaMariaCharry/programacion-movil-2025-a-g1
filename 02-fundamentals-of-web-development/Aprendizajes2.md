## Aprendizajes del curso de Fundamentos del desarrollo web
## 1. Aspectos básicos del desarrollo web 
Después de haber completado este curso, tengo una comprensión sólida de las funciones informáticas básicas y de cómo operan los sistemas. Puedo describir con claridad la diferencia entre hardware y software, así como las principales funciones de cada componente dentro de un sistema informático.

Aprendí sobre los distintos tipos de lenguajes de programación y cómo un sistema interpreta y ejecuta el código. También comprendí la diferencia entre el diseño web, enfocado en la apariencia y experiencia del usuario, y el desarrollo web, centrado en la funcionalidad y estructura del sitio.

Entiendo ahora los componentes esenciales de un sitio web y conozco las principales etapas del proceso de desarrollo web, desde la planificación hasta el despliegue. Sé diferenciar entre los procesos que ocurren del lado del cliente (front-end) y del lado del servidor (back-end), así como los lenguajes más comunes que se utilizan en cada uno de ellos. Por ejemplo, HTML, CSS y JavaScript para el front-end, y lenguajes como Python, PHP o Node.js para el back-end.

Además, ahora puedo distinguir claramente entre la Internet y la World Wide Web, conceptos que muchas veces se confunden. Por último, entendí cómo el uso de la nube ha transformado el desarrollo web, permitiendo mayor escalabilidad, flexibilidad y colaboración en tiempo real. 

## 2. Desarrollo de sitios para la web
Después de completar este curso, he comprendido cómo los desarrolladores web crean sitios web modernos, desde los lenguajes utilizados hasta las metodologías de desarrollo. Ahora puedo identificar claramente la finalidad de los exploradores web y su papel en la visualización e interpretación del contenido desarrollado.

Aprendí sobre los lenguajes de marcado, como HTML, su estructura y evolución, y los desafíos que ayudan a superar. Comprendo cómo HTML define el contenido básico de una página web y cómo HTML5 introdujo mejoras significativas como nuevas etiquetas semánticas, soporte multimedia y mejor interacción con APIs.

También estudié CSS, entendiendo sus características, funciones y cómo controla la presentación visual de los sitios web. En conjunto, vi cómo JavaScript aporta interactividad, permitiendo que el contenido reaccione al comportamiento del usuario. Aprendí cómo JavaScript interactúa tanto con HTML como con CSS para generar experiencias dinámicas y atractivas.

Además, entendí las fases del ciclo de vida del desarrollo de software (SDLC), desde la planificación hasta el mantenimiento, y pude diferenciar entre el enfoque tradicional en cascada y el enfoque ágil. Este último, más flexible y colaborativo, mejora la eficiencia en el desarrollo web. Dentro del enfoque ágil, conocí el marco Scrum, que estructura el trabajo en sprints y promueve la mejora continua mediante roles bien definidos y reuniones regulares.

## 3. Introducción a HTML y CSS 
Este curso me permitió comprender cómo se estructura una página web desde sus fundamentos. Aprendí a utilizar elementos HTML para construir el contenido de una página y reconozco los elementos más comunes que forman la base de cualquier sitio web moderno, como encabezados, párrafos, listas, enlaces e imágenes.

También comprendí qué son los atributos HTML, cuáles son los más utilizados y cómo permiten definir propiedades adicionales en los elementos para mejorar su funcionalidad y personalización. Además, entendí la importancia de organizar correctamente el código HTML, tanto para facilitar su mantenimiento por parte de los desarrolladores como para mejorar la experiencia del usuario final.

Exploré cómo se aplica CSS al HTML para dar estilo a las páginas, así como los distintos métodos disponibles para hacerlo: en línea, interno y externo. Aprendí en detalle el modelo de cuadro de CSS (box model), comprendiendo cómo funcionan los márgenes, bordes, relleno y contenido para estructurar visualmente los elementos.

Finalmente, reconocí las buenas prácticas que se deben seguir al escribir código HTML y CSS, incluyendo la limpieza del código, el uso adecuado de indentaciones, nombres descriptivos y comentarios. También conocí las características más útiles de un entorno de desarrollo integrado (IDE), como el resaltado de sintaxis, la autocompletación y la depuración, que ayudan a mejorar la eficiencia y el flujo de trabajo en el desarrollo web. 

## 4. Creación de sitios web dinámicos con JavaScript 
A lo largo de este curso, aprendí cómo los desarrolladores web utilizan JavaScript junto con HTML para crear sitios web dinámicos e interactivos. Comprendí la sintaxis de JavaScript y cómo se integran scripts en una página web mediante distintas técnicas, como etiquetas <script> internas y externas.

Exploré conceptos clave como variables, funciones, expresiones, operadores y eventos, y cómo estos elementos permiten manipular el contenido y el comportamiento de una página en respuesta a las acciones del usuario. Además, estudié el uso de objetos en JavaScript y conocí los tipos de datos más comunes que se manejan en este lenguaje.

También aprendí sobre modelos de programación, entendiendo sus diferencias y aplicabilidad en el desarrollo web. Profundicé en el uso de datos en los sitios web y en cómo interactuar con bases de datos utilizando MySQL. Reconozco ahora las cuatro funciones principales de una base de datos (crear, leer, actualizar y eliminar datos) y sé interpretar la sintaxis básica de MySQL para ejecutar estas operaciones.

Finalmente, conocí el entorno de ejecución Node.js, entendiendo su propósito y las ventajas que ofrece para el desarrollo del lado del servidor. Asimismo, descubrí el valor de los marcos (frameworks) y bibliotecas para agilizar y optimizar el desarrollo web, especialmente cuando se trabaja con JavaScript. 

## 5. Prueba y despliegue de sitios web 
Durante este curso, adquirí conocimientos clave sobre las prácticas que los desarrolladores web aplican para garantizar la calidad y estabilidad de los sitios antes de hacerlos públicos. Aprendí a identificar los distintos tipos de pruebas que se realizan, tanto manuales como automatizadas, y comprendí sus ventajas para detectar errores, mejorar la experiencia del usuario y acelerar los ciclos de desarrollo.

Exploré cómo los sistemas de control de versiones, como Git, permiten a los equipos colaborar eficientemente y entregar nuevas características de forma más rápida y organizada. También comprendí los pasos necesarios para publicar un sitio web, desde la preparación del entorno hasta su despliegue en servidores locales o en la nube.

Entendí la diferencia entre entrega continua y despliegue continuo, así como la finalidad del enfoque DevOps, que integra desarrollo y operaciones en un solo flujo de trabajo para mejorar la agilidad, la calidad y la eficiencia en todo el ciclo de vida del software.

Aprendí qué es el diseño reactivo (responsive design) y por qué es fundamental para que un sitio web funcione correctamente en distintos dispositivos. También comprendí la diferencia entre entregar contenido como un sitio web tradicional y como una aplicación web interactiva.

Además, exploré conceptos modernos como la inclusión en contenedores frente al uso de máquinas virtuales, y cómo estas tecnologías mejoran la escalabilidad y portabilidad del software. Finalmente, reconocí las herramientas más comunes para probar y automatizar el despliegue de sitios web, y cómo la computación en la nube y el uso de contenedores optimizan el desarrollo y despliegue web en entornos profesionales. 

## 6. Desarrollar una página web de lista de tareas interactive 
En este curso, llevé a la práctica los conocimientos adquiridos previamente mediante el desarrollo de una página web interactiva de lista de tareas. A lo largo de las simulaciones, identifiqué las herramientas y habilidades necesarias para crear un sitio web funcional desde cero.

Comencé revisando los requisitos del proyecto y analizando un diagrama de wireframes, lo que me permitió planificar y definir mejor la estructura y funcionalidad del sitio. Utilicé Visual Studio Code (VS Code) como entorno de desarrollo integrado (IDE), configurando correctamente los archivos y carpetas del proyecto.

Desarrollé la estructura básica de la página utilizando HTML, asegurando una organización clara del contenido. Luego apliqué estilos visuales con CSS para mejorar la presentación y lograr una interfaz más atractiva. Posteriormente, utilicé JavaScript para incorporar elementos interactivos, como la posibilidad de añadir y eliminar tareas, haciendo que la página respondiera dinámicamente a las acciones del usuario.

Finalmente, realicé pruebas funcionales simples para asegurarme de que el sitio web se comportara como se esperaba, corrigiendo errores y validando el cumplimiento de los objetivos propuestos. Esta experiencia me permitió integrar y aplicar de forma práctica los conocimientos sobre desarrollo web en un proyecto realista.

## 7. Su futuro en el desarrollo web: el panorama laboral 
Al finalizar este curso, adquirí una visión más amplia sobre el mercado laboral del desarrollo web y las competencias necesarias para destacar en este campo. Pude identificar los sectores en los que se desempeñan los desarrolladores web, comprendiendo que su trabajo es fundamental en industrias tan diversas como la tecnología, la educación, el comercio electrónico, la salud y muchas más.

Analicé la creciente demanda global de profesionales del desarrollo web, así como las oportunidades que esta tendencia representa para el futuro del sector. También conocí los roles más comunes dentro del campo, como desarrollador front-end, back-end y full-stack, y comprendí las responsabilidades asociadas a cada uno.

Estudié las habilidades técnicas y blandas necesarias para tener éxito como desarrollador web, incluyendo la capacidad de trabajar en equipo, resolver problemas, adaptarse a nuevas tecnologías y comunicarse eficazmente con otros profesionales del área, como diseñadores UX/UI, testers, administradores de bases de datos y gerentes de proyectos.

Además, aprendí a diferenciar los distintos roles dentro de un equipo de desarrollo y comprendí la importancia de la colaboración entre ellos para alcanzar los objetivos de un proyecto. Finalmente, descubrí recursos clave para seguir aprendiendo y mantenerme actualizado en un entorno tan cambiante como el del desarrollo web, lo cual es esencial para el crecimiento profesional continuo.
